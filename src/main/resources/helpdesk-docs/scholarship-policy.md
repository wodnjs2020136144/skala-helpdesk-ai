# 장학금 규정

## 제1조 (성적 장학금)
1. 직전 학기 평점평균(GPA) 4.0 이상: 등록금 전액 면제.
2. 직전 학기 평점평균(GPA) 3.7 이상 4.0 미만: 등록금 50% 면제.
3. 직전 학기 평점평균(GPA) 3.5 이상 3.7 미만: 등록금 30% 면제.
4. 직전 학기 12학점 미만을 이수한 경우 성적 장학금 대상에서 제외한다.

## 제2조 (중복 수혜 제한)
1. 성적 장학금과 국가장학금은 중복 수혜가 가능하나, 등록금 총 면제액이 등록금을
   초과할 수 없다.
2. 교내 근로장학금은 성적 장학금과 중복 수혜할 수 있다.

## 제3조 (장학금 신청)
1. 성적 장학금은 성적 발표 후 자동으로 산정되며 별도 신청이 필요 없다.
2. 국가장학금·근로장학금은 학기별 지정 기간에 학생이 직접 신청해야 하며,
   신청은 학사팀 승인 후 확정된다.
