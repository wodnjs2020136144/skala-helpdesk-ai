# 학사규정 코퍼스 — 출처

`IngestService`가 `helpdesk-docs/*.md` 앵커 3종(Tool 반환값과 정합성이 맞춰져 있어
교체하지 않는다)에 더해 인제스트하는 확장 코퍼스다. 청크 3~6개뿐이던 앵커만으로는
top-k·threshold 튜닝, `docType`·`dept` 메타데이터 필터링, 유사 조항(휴학/자퇴/제적) 검색
실패 관찰이 불가능해 추가했다. 자세한 배경은 `IngestService` 클래스 Javadoc 참고.

## 출처

한국기술교육대학교 내규관리시스템(https://rule.koreatech.ac.kr) — 로그인 없이 공개 열람
가능. 취득일 2026-08-20, 각 규정 상세 화면의 **「PDF 다운」** 버튼으로 받았다.

⚠️ 「전문다운」 버튼은 HWP를 내려받는다 — `TikaDocumentReader`는 HWP를 읽지 못하므로
**반드시 「PDF 다운」을 쓴다.**

| 파일 | 규정명 | 분야(docType) | 담당부서(dept) | 개정일(version) |
|---|---|---|---|---|
| `한국기술교육대학교_학칙.pdf` | 한국기술교육대학교 학칙 | `학칙` | 교무팀 | 2026-03-31 |
| `학사운영에관한규칙.pdf` | 학사운영에 관한 규칙 | `교무행정` | 학사팀 | 2026-04-01 |
| `장학금에관한규칙.pdf` | 장학금에 관한 규칙 | `학생행정` | 학생지원팀 | 2026-05-01 |

`docType`·`dept`·`version` 값은 각 규정 상세 화면(좌측 분야 트리 / 우측 상단 "담당부서" /
상단 "N차 개정" 최신값)에서 읽은 실측값이며, `IngestService#ingestOnStartup`에 그대로
하드코딩돼 있다. 개정되면 이 표와 코드를 함께 갱신한다.

## 검토된 대안 — 채택하지 않음

`2026대학요람(한국기술교육대학교).pdf`(363p)를 검토했으나 코퍼스에서 제외했다:

- 학칙 조항 **본문이 없다** — p.353 "학칙 및 주요규정 목록"은 규정 제목만 나열하고 위
  내규관리시스템을 참고하라고 안내한다.
- 교원·직원 **실명 명단**이 14페이지(p.303–316) 있어 그대로 인제스트하면 남의 정보를
  RAG가 답해버린다(레드팀 체크리스트와 정면 충돌).
- 교과목 표 230페이지(p.73–302)가 Tika 추출 시 청크를 지배해 검색 결과를 도배한다.

필요해지면 p.39–72 "대학교육과정 운영기준"만 잘라 추가하는 것을 고려한다.
