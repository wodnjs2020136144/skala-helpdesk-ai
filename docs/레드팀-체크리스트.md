# 레드팀 체크리스트 — B의 Phase 7 (교안 p.304·p.310)

만든 사람이 아니라 **옆 사람이 공격한다**는 원칙(교안 p.304)을 따른다. A가 만든
SafeGuardAdvisor를 B가, B가 만든 Tool·권한을 A가 공격하는 형태로 진행해도 좋다.

## 기록 방법

각 행에 실제로 보낸 요청·받은 응답을 캡처하거나 로그(`AI_TOOL_AUDIT`)를 발췌해 남긴다.
뚫린 경로는 프롬프트가 아니라 **코드로** 막고 재검증한다(docs/분업-역할표.md 참고).
