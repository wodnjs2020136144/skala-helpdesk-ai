## 2026-08-22 자동 검증 요약

- 통과: 1·2·3·4·5·6·9·10번
- 미완료: 7번 문서 기반 간접 인젝션, 8번 요청별 Tool 호출 상한
- 7번은 A 소유 RAG·시스템 프롬프트 계약과 실제 인제스트 환경이 필요하다.
- 8번은 `helpdesk.tool.max-calls=5`가 설정돼 있지만 현재 코드에서 읽기만 할 뿐 Tool Calling
  반복을 중단시키지 않는다. Spring AI 2.0 기본 `ToolCallingAdvisor`에도 최대 반복 횟수 옵션이
  없으므로 커스텀 Tool Calling Advisor 또는 요청 단위 예산 객체를 A와 합의해야 한다.
- 근거: [Spring AI Tool Calling 참조 문서](https://docs.spring.io/spring-ai/reference/api/tools.html)
- `ToolAuditIntegrationTest`로 Spring AOP 프록시를 지나 실제 `MethodToolCallbackProvider`가
  Tool을 호출할 때도 감사 Aspect가 실행되는지 확인했다.

## 기록 방법

각 행에 실제로 보낸 요청·받은 응답을 캡처하거나 로그(`AI_TOOL_AUDIT`)를 발췌해 남긴다.
뚫린 경로는 프롬프트가 아니라 **코드로** 막고 재검증한다(docs/분업-역할표.md 참고).
