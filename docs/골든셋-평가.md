# Phase 8 Golden Set 평가

교재의 결정적 테스트 원칙에 따라 모델 답변 전체 문장을 비교하지 않고, 문항별 핵심 사실과
출처, Tool 사용 여부를 검사한다. 사용자 요구에 맞춰 기준선은 20문항으로 구성했다.

## 문항 구성

| 범주 | ID | 개수 | 검사 내용 |
|---|---|---:|---|
| 학사운영규정 | `AC-01`~`AC-05` | 5 | 신청학점, 정정, 철회, 이의신청 |
| 졸업요건 | `GR-01`~`GR-05` | 5 | 총·전공학점, 어학, 캡스톤, 졸업 사정 |
| 장학금 | `SC-01`~`SC-04` | 4 | 성적 구간, 최소 이수학점, 신청 방식 |
| Tool | `TL-01`~`TL-03` | 3 | 학적 조회, 졸업 상태, 철회 접수 |
| 근거 없음 | `NE-01`~`NE-03` | 3 | 식단, 기숙사 통금, 주차 요금 |

기대 출처가 있는 15문항은 해당 파일이 `sources`에 포함되는지 확인한다. Tool 전용 2문항은
출처를 평가하지 않고 Tool 사용과 핵심 반환값을 검사한다. 근거 없음 3문항은 `sources`가
비어 있고 안전 문구가 포함되는지 확인한다.

## 실행 방법

일반 단위 테스트와 빌드는 실제 모델을 호출하지 않는다.

```bash
./gradlew test
./gradlew build
```

실제 평가는 OpenAI 키와 실행 중인 pgvector가 필요하다. 애플리케이션과 같은 DB 환경변수를
설정한 뒤 아래 태스크를 실행한다.

```bash
export OPENAI_API_KEY="..."
./gradlew goldenSetTest
```

결과는 `build/reports/golden-set/results.md`에 생성된다. 이 파일에는 답변 원문을 남기지 않고
문항별 PASS/FAIL, 지연시간, 실제 출처, 오류 유형만 기록한다. Tool 오류율은 예외 발생뿐
아니라 기대한 Tool 미호출과 핵심 반환값·출처 검증 실패를 포함하며 `1 - Tool 성공률`로
계산한다.

기본 합격 기준은 전체·출처·Tool·근거 없음 각각 80% 이상, 호출 오류 0건,
비스트리밍 P95 5초 이하이다. 필요하면 아래 환경변수로 기준만 재설정할 수 있다.

- `GOLDEN_SET_MIN_PASS_RATE`
- `GOLDEN_SET_MIN_SOURCE_HIT_RATE`
- `GOLDEN_SET_MIN_TOOL_SUCCESS_RATE`
- `GOLDEN_SET_MIN_NO_EVIDENCE_RATE`
- `GOLDEN_SET_MAX_P95_MS`

실제 평가 결과와 Actuator의 `ai.tokens`, `ai.latency`, 모델 폴백 결과는 A의 Phase 8 변경을
현재 브랜치에 반영한 뒤 작업순서 문서와 검증 시나리오에 기록한다.

## 2026-08-22 실제 OpenAI·pgvector 평가 결과

B(박성우)가 `./gradlew goldenSetTest`를 실행했다. 20문항의 모델 호출은 모두
완료됐고 호출 오류는 없었지만, 전체와 근거 없음 기준이 80% 미만이어서 테스트는
실패로 종료됐다. 기준을 낮추지 않고 품질 회귀로 기록한다.

| 지표 | 실측 | 기준 | 결과 |
|---|---:|---:|:---:|
| 전체 통과율 | 75.0% | 80% 이상 | FAIL |
| 필수 출처 적중률 | 86.7% | 80% 이상 | PASS |
| Tool 성공률 | 100.0% | 80% 이상 | PASS |
| Tool 오류율 | 0.0% | - | 기록 |
| 근거 없음 통과율 | 33.3% | 80% 이상 | FAIL |
| 비스트리밍 P95 | 2,566ms | 5,000ms 이하 | PASS |
| 호출 오류 | 0건 | 0건 | PASS |

실패 문항은 `AC-01`, `AC-05`, `SC-04`, `NE-02`, `NE-03`이다. `AC-01`과
`AC-05`는 공식 PDF를 검색했지만 기대한 요약 문서와 핵심 문구를 만족하지 못했고,
`SC-04`는 기대 출처는 적중했지만 핵심 문구 판정을 통과하지 못했다. `NE-02`와
`NE-03`은 근거가 없는 질문에도 PDF 출처가 반환됐다.

### 계측·폴백 실측

- 정상 통합 요청 6건 후 `ai.tokens` 8,562와 `ai.latency` 6건(총 11.370초,
  최대 2.536초)을 Actuator에서 확인했다.
- 주 모델을 존재하지 않는 값으로 주입했을 때 HTTP 200과 정상 출처가 반환됐다.
  `ai.errors{exception=NotFoundException}=1`, `ai.fallback{outcome=success}=1`이고,
  대화 메모리는 user·assistant 2건만 남아 재시도 중복이 없었다.
- 주 모델과 폴백 모델을 모두 장애 주입했을 때 HTTP 500, 안전 문구,
  traceId가 반환됐고 Health는 `UP`을 유지했다.
- 추가 관찰: 주·폴백 모두 실패한 세션에는 사용자 메시지 1건이 남았다.
  안전 응답 계약은 통과했지만 최종 실패 시 메모리 롤백은 후속 검토가 필요하다.
